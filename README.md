# 🍕 Pizza App — Cotizador y Gestor de Pedidos

Aplicación web interactiva para personalizar pedidos de pizzería, seleccionar ingredientes adicionales y calcular el valor total en tiempo real con formato de moneda colombiana (COP).

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Formulario interactivo de selección de productos y extras.
* **CSS3:** Diseño centrado tipo tarjeta con retroalimentación visual.
* **JavaScript (ES6+):** Escucha de eventos en tiempo real (`input`, `change`), validaciones y formateo numérico (`toLocaleString("es-CO")`).

## ✨ Funcionalidades Principales

* **Personalización de Pedido:** Selección de especialidad de pizza, cantidad e ingredientes extra con contador dinámico.
* **Vista Previa en Tiempo Real:** Cálculo automático del subtotal mientras el usuario modifica opciones.
* **Validación de Datos:** Control de cantidades inválidas con mensajes de error claros.
* **Resumen Final:** Desglose detallado del pedido incluyendo costo de domicilio.

## 🚀 Ejecución

1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en tu navegador web o ejecútalo mediante **Live Server** en Visual Studio Code.
